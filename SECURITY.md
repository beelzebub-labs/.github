# Security Policy

This policy applies to all repositories in the [beelzebub-labs](https://github.com/beelzebub-labs) organization, unless a repository provides its own `SECURITY.md`.

## Supported Versions

Security fixes are released for the latest version of each project. Please upgrade to the most recent release before reporting an issue.

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Send reports to [security@beelzebub.ai](mailto:security@beelzebub.ai) and include:

- The affected project and version
- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof of concept
- Any suggested mitigation, if known

We aim to acknowledge reports within 48 hours. Once an issue is confirmed, we will work on a fix and coordinate disclosure with you. We are happy to credit reporters in the release notes unless you prefer to remain anonymous.
